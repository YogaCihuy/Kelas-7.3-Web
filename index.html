Kelas 7.3 di iPhone

Apple gak ngizinin file aplikasi dibuka langsung kayak APK Android, jadi ada 2 cara:

Cara 1: Tambah ke Layar Utama (paling gampang)

  1. Buka web ini lewat Safari.
  2. Tekan tombol Bagikan (kotak dengan panah ke atas).
  3. Pilih Tambah ke Layar Utama (Add to Home Screen), lalu Tambah.

Jadi ikon app lengkap dengan loading screen. Notifikasi eskul cuma bunyi pas app lagi kebuka.

Cara 2: File aplikasi (.ipa)

Notifikasi eskul tetap bunyi walau app ditutup. Pasangnya lewat AltStore atau Sideloadly (butuh komputer + Apple ID, dan harus dipasang ulang tiap 7 hari).
